# Менеджер нотаток

Простий консольний застосунок для створення, перегляду, пошуку та видалення нотаток. Дані зберігаються у JSON-файлі, дії записуються у лог.

## Технології

- Python 3.10+
- JSON
- `unittest`
- Git

## Запуск

```bash
python3 main.py
```

Програма автоматично створить `data/notes.json` після додавання першої нотатки.

## Тести

```bash
python3 -m unittest -v
```

## Структура

- `main.py` — консольний інтерфейс;
- `note_manager.py` — модель даних і бізнес-логіка;
- `test_note_manager.py` — автоматичні тести;
- `data/notes.json` — файл даних, створюється автоматично;
- `app.log` — журнал подій, створюється автоматично.

## Серверна частина — практика, частина 2

У папці `server/` знаходиться REST API на Node.js + Express. Він містить:

- CRUD API для нотаток, категорій і тегів;
- SQLite та Sequelize ORM;
- DI-контейнер Awilix;
- CORS, журналювання запитів і централізовану обробку помилок;
- Swagger UI за адресою `/api-docs`.

Запуск серверної частини:

```bash
cd server
npm install
cp .env.example .env
npm start
```
